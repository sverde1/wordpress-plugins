Display available server disk space on the Dashboard.

== Description ==

This plugin displays you available server disk space in main Dashboard window, so you can see when you have to expand your storage plan.

== Installation ==

1. Upload `watermark-reloaded/` to the `/wp-content/plugins/` directory
1. Activate the plugin through the 'Plugins' menu in WordPress
